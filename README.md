# 🎯 Jogo de Adivinhação

Projeto desenvolvido em JavaScript com o objetivo de praticar lógica de programação, manipulação do DOM, funções, estruturas condicionais e controle de estado.

O jogo gera um número aleatório entre **1 e 100**, e o jogador deve tentar descobrir qual é o número secreto antes que suas tentativas acabem.

## 🚀 Funcionalidades

- Geração de um número aleatório entre 1 e 100;
- Validação do número informado pelo jogador;
- Indicação se o número secreto é maior ou menor que o palpite;
- Controle da quantidade de tentativas restantes;
- Exibição da quantidade de tentativas realizadas ao acertar;
- Exibição do número secreto caso as tentativas acabem;
- Bloqueio do botão ao finalizar a partida.

## 🕹️ Como jogar

1. Digite um número entre **1 e 100**.
2. Clique no botão **Chutar**.
3. O jogo informará se o número secreto é maior ou menor que o seu palpite.
4. Continue tentando até acertar ou acabar o número máximo de tentativas.
5. Ao acertar, o jogo mostra quantas tentativas foram realizadas.

## 📚 Conceitos praticados

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Variáveis e constantes;
- Funções;
- Arrow Functions;
- Parâmetros e argumentos;
- Estruturas condicionais (`if`, `else if` e `else`);
- Operadores lógicos;
- Manipulação do DOM;
- Conversão e validação de valores;
- Template literals;
- Geração de números aleatórios com `Math.random()`;
- Controle de estado;
- Refatoração de código;
- Uso de constantes para evitar *magic numbers*.
